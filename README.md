# 日語天台宗

不判人，只判域
不执音，执活人
不废干慧，只盖章

**宗義**：① 判教——一切学路各归其域，不排座次，只判管辖；② 三諦——原音為空、諸変体為仮、活人為中；③ 六即分域——理即 → 名字即（干慧位）→ 観行即（止観＝输入＋noticing）→ 相似即 → 分真即，究竟即分域，無総体究竟。

**門風**：教観一致——meta-guide 為教，quiz・原声為観；判教文本即修行指南。

**検品**：本宗为读解学习所作的投射（脚手架），并非宗派实体——不借伞立威。

**宗規**：一判一観——每出一则判教，须结算一次観行（听一段・读一页・写一句）；判而不観，判词自动转送 [ganhui](https://syu-toutousai.github.io/ganhui/) 备案。
